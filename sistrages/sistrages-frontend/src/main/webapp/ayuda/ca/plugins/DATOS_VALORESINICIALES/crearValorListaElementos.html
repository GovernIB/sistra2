crearValorListaElementos(): ValorCampoListaElementos

DESCRIPCIÓ

  • Mètode per a crear un valor de llista d'elements per a després poder utilitzar-lo en un camp del formulari.

PARÀMETRES DE SORTIDA

  • ValorCampoListaElementos: Retorna l'objecte ValorCampoListaElementos inicialitzat, el qual permet afegir nous valors.

EXEMPLES

Per exemple, per a generar una sèrie de valors per a una llista d'elements:

var datos = DATOS_VALORESINICIALES.crearValorListaElementos();

D'aquesta manera podem afegir els nous valors a la variable fent servir els mètodes:

  • 'addValor(codi, descripció)', on el primer paràmetre indica el codi i el segon paràmetre el valor.
  • 'addValorCompuesto(camp, codi, descripció)', on el primer paràmetre indica el camp al qual es vol assignar el valor, el segon paràmetre el codi que es vol assignar al camp i el tercer el valor.
  • 'addValorMultiple(camp, valor)', on el primer paràmetre indica el camp al qual es vol assignar el valor i el segon paràmetre el valor sent aquest una variable múltiple.

datos.addValor('codi', '07073');
datos.addValor('descripcio', 'Mallorca');
datos.addValorCompuesto('provincia', '07', 'Illes Balears');
datos.addValorMultiple('datosGeografico', multiple);
