addPago(PagoDinamico pago): void

DESCRIPCIÓ

  • Mètode que permet afegir un nou pagament de manera dinàmica a la versió del tràmit.

PARÀMETRES D'ENTRADA

  • pago: variable de tipus Pagament Dinàmic amb els valors establerts.

EXEMPLES

Si desitgem afegir un nou pagament de manera dinàmica a la versió d'un tràmit, executaríem el següent:

var nif = 'nif1';
var apellido1 = 'ape1';
var apellido2 = 'ape2';
var concepto = 'concepto1';
var nombreCompleto = 'nom1';
var modelo = 'modelo1';
var unidades = 3;
if ( !PLUGIN_UTILS.esCadenaVacia( apellido1 ) )
{
nombreCompleto += ' ' + apellido1;
if ( !PLUGIN_UTILS.esCadenaVacia( apellido2 ) )
{
nombreCompleto += ' ' + apellido2;
}
}
DATOS_PAGOSDINAMICOS.setContribuyente( nif, nombreCompleto );
DATOS_PAGOSDINAMICOS.setPasarela( 'ATIB' );
DATOS_PAGOSDINAMICOS.setOrganismo( 'ORG1' );
DATOS_PAGOSDINAMICOS.setMetodosPago('TJ');
var tasa = 'TASA1';
var importe = 1;
if (PLUGIN_UTILS.esCadenaVacia(unidades)) {
DATOS_PAGOSDINAMICOS.setDetallePago( modelo, concepto, tasa, importe );
} else {
DATOS_PAGOSDINAMICOS.setDetallePago( modelo, concepto, tasa, unidades, importe );
}

El resultat de l'execució de l'script "Llista dinàmica de pagaments" amb aquesta sentència serà un pagament que és obligatori amb les dades establertes. Depenent de si s'introdueix un nombre específic d'unitats, el pagament es realitzarà una o més vegades.
