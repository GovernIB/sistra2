PAGO_DINAMICO

DESCRIPCIÓN

  • Objecte que modela un pagament que es pot afegir de manera dinàmica.

MÈTODES

  • setContribuyente(String nif, String nombreCompleto): Identificador del contribuent del pagament (Obligatori).
  • setPasarela(String pasarela): Passarel·la de pagament associada al pagament (Obligatori).
  • setOrganismo(String organisme): Organisme associat al pagament (Obligatori).
  • setMetodosPago(String metodesPagament): Mètodes de pagament associats al pagament. Per introduir diversos mètodes, separats per ';' (Obligatori).
  • setDetallePago(String model, String concepte, String taxa, int import): Permet establir els detalls del pagament, incloent el model, concepte, taxa i import.
  • setDetallePago(String model, String concepte, String taxa, int unitats, int import): Permet establir els detalls del pagament, incloent el model, concepte, taxa, unitats i import.
