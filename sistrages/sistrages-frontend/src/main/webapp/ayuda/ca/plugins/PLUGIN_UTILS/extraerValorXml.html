extraerValorXml(String xml, String xpath): String

DESCRIPCIÓ

  • Extreu el valor del node XML representat pel XPath indicat.
  • L'XML ha d'estar ben format, i el XPath ha de contenir una ruta vàlida a un node de l'XML

PARÀMETRES D'ENTRADA

  • xml: Cadena amb estructura d'XML. Ha de contenir un XML ben format
  • xpath: Cadena que conté el XPath. Conté una seqüència de tags de l'XML, que marquen la ruta cap al node del qual volem extreure el valor.

PARÀMETRES DE SORTIDA

  • String: Valor del node indicat en el paràmetre XPath. Si la ruta indicada en el XPath no existeix, retorna un error.

EXEMPLES

Exemple 1 Extreure el valor del node 'dni' en l'XML. Per a això, hem de revisar l'estructura completa de l'XML, i obtenir el XPath adequat. En aquest cas el XPath serà'/xml/persona/dni'

var xml = 'juan79865432D';
var dni = PLUGIN_UTILS.extraerValorXml(xml, '/xml/persona/dni');

La funció extraerValorXml retorna '79865432D', que és el valor del node dni.


Exemple 2 Pot ocórrer que el node del qual intentem obtenir el valor no existeixi en l'XML. Per exemple, si intentem usar el següent XPath '/xml/persona/apellido', fent servir el mateix XML de l'anterior exemple:

var xml = 'juan79865432D';
var persona = PLUGIN_UTILS.extraerValorXml(xml, '/xml/persona/apellido');

La funció extraerValorXml retorna un error, ja que '/xml/persona/apellido' no existeix com a node en l'XML facilitat.
