getXml(String idFormulario): String

DESCRIPCIÓ

  • Mètode que retorna l'XML amb els valors del formulari.

PARÀMETRES D'ENTRADA

  • idFormulario: Cadena que conté l'identificador del formulari.

PARÀMETRES DE SORTIDA

  • string: Cadena de caràcters que representa l'XML amb els valors del formulari.

Exemple

Obtenir l'XML del formulari amb identificador 'Form1':

var xml = PLUGIN_FORMULARIOS.getXml('Form1');

La funció getXml retornarà una cadena de text on el contingut serà el XML del formulari amb els seus valors.
D'aquest XML es podria extreure el valor d'un determinat camp, per Exemple si sabem que en l'XML existeix un camp dni amb el següent xpath '/xml/persona/dni' podríem obtenir el valor del camp DNI mitjançant:

var dni = PLUGIN_VALIDACIONES.extraerValorXml(xml, '/xml/persona/dni');

La funció extraerValorXml retornarà el valor del camp dni dins de l'XML, en aquest cas '11111111H'.
