esFormatoFecha(String formatoFecha): boolean

DESCRIPCIÓ

  • Verifica que el format de data introduït no sigui nul ni buit i sigui vàlid.

PARÀMETRES D'ENTRADA

  • formatoFecha: Format de la data. Els formats vàlids són dd/MM/yyyy i yyyy-MM-dd.

PARÀMETRES DE SORTIDA

  • boolean: true si el format de data és vàlid i false si el format no és vàlid.

EXEMPLES

Exemple 1 Validar una cadena de caràcters buida ''

var valido = PLUGIN_UTILS.esFormatoFecha('');

La funció esFormatoFecha retorna 'false', a causa que el valor indicat no és un format vàlid.


Exemple 2 Validar una cadena de caràcters nul·la.

var fecha;
var valido = PLUGIN_UTILS.esFormatoFecha(null);

La funció esFormatoFecha retorna 'false', a causa que el valor indicat no és un format vàlid.


Exemple 3 Validar la cadena de caràcters 'yyyy-MM-dd'.

var valido = PLUGIN_UTILS.esFormatoFecha('yyyy-MM-dd');

La funció esFormatoFecha retorna 'true', ja que el valor indicat és un format de data vàlid.


Exemple 4 Validar la cadena de caràcters 'dd/MM/yyyy'.

var valido = PLUGIN_UTILS.esFormatoFecha('dd/MM/yyyy');

La funció esFormatoFecha retorna 'true', ja que el valor indicat és un format de data vàlid.


Exemple 5 Validar la cadena de caràcters 'dd-MM-yyyy'.

var valido = PLUGIN_UTILS.esFormatoFecha('dd-MM-yyyy');

La funció esFormatoFecha retorna 'false', a causa que el valor indicat no és un format vàlid.
