esFormatoHora(String formatoHora): boolean

DESCRIPCIÓ

  • Verifica que el format d’hora introduït no sigui nul ni buit i sigui vàlid.

PARÀMETRES D'ENTRADA

  • formatoHora: Format de l'hora. Els formats vàlids són HH:mm i HH:mm:ss.

PARÀMETRES DE SORTIDA

  • boolean: true si el format d’hora és vàlid i false si el format no és vàlid.

EXEMPLES

Exemple 1 Validar una cadena de caràcters buida ''

var valido = PLUGIN_UTILS.esFormatoHora('');

La funció esFormatoHora retorna 'false', a causa que el valor indicat no és un format vàlid.


Exemple 2 Validar una cadena de caràcters nul·la.

var hora;
var valido = PLUGIN_UTILS.esFormatoHora(null);

La funció esFormatoHora retorna 'false', a causa que el valor indicat no és un format vàlid.


Exemple 3 Validar la cadena de caràcters 'HH:mm'.

var valido = PLUGIN_UTILS.esFormatoHora('HH:mm');

La funció esFormatoHora retorna 'true', degut a que el valor indicat és un format d'hora vàlid.


Exemple 4 Validar la cadena de caràcters 'HH:mm:ss'.

var valido = PLUGIN_UTILS.esFormatoHora('HH:mm:ss');

La funció esFormatoHora retorna 'true', degut a que el valor indicat és un format d'hora vàlid.


Exemple 5 Validar la cadena de caràcters 'HH-mm'.

var valido = PLUGIN_UTILS.esFormatoHora('HH-mm');

La funció esFormatoHora retorna 'false', a causa que el valor indicat no és un format vàlid.
