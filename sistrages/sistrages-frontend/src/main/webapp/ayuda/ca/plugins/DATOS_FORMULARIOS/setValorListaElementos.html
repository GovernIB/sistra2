setValorListaElementos(idFormulario, campo,valorCampoListaElementos): void

DESCRIPCIÓ

  • Mètode que estableix un valor llista elements a un camp del formulari actual o posterior.

PARÀMETRES D'ENTRADA

  • idFormulario: Identificador del formulari en el qual vol modificar el valor del camp.
  • campo : Identificador del camp del formulari.
  • valorCampoListaElementos : Objecte de tipus ValorListaElementos el qual conté els diferents valors a assignar al camp.

EXEMPLES

S'inicialitza una variable per a assignar-la a un camp multiregistre del formulari 'FORM2' i anar afegint valors mitjançant la funció addValor:

var datos = DATOS_FORMULARIOS.crearValorListaElementos(); var valorElemento=datos.addElemento(); valorElemento.addValor('codigo', '07073'); valorElemento.addValor('descripcion', 'Mallorca');

Una vegada creada la variable, creat l'element i assignats els valors, es podrà assignar al camp corresponent.

DATOS_VALORESINICIALES.setValorListaElementos('FORM2','TABLA_MUNICIPIOS',datos);

El següent script serveix per a omplir la llista d'elements 'LEL2' d'un formulari 'FORM-2' amb els valors d'una altra llista d'elements 'LEL1' del formulari 'FORM-1' tenint en compte que totes dues llistes compten amb dos camps 'LTX1' i 'LTX2'.

var numeroElementos = PLUGIN_FORMULARIOS.getNumeroElementos('FORM-1','LEL1');
var lel = DATOS_FORMULARIOS.crearValorListaElementos();
var i = 0;

if (numeroElementos != null) {
 while(i < numeroElementos){
  var e = lel.addElemento();
  e.addValor('LTX1', PLUGIN_FORMULARIOS.getValorElemento('FORM-1','LEL1',i,'LTX1'));
  e.addValor('LTX2', PLUGIN_FORMULARIOS.getValorElemento('FORM-1','LEL1',i,'LTX2'));
var compDom = PLUGIN_DATOSFORMULARIO.getValorElementoCompuesto('FORM1','LEL2',i,'LELUNICAHORIZONTAL'); e.addValorCompuesto('LEL4COMPUESTO', compDom.getCodigo(), compDom.getDescripcion()); var total = PLUGIN_FORMULARIOS.getNumeroValoresValorElementoMultiple('FORM1','LEL2',i,'LELMULTIPLEDOMINIO'); if (total > 0) { var cont = 0; var multiple = DATOS_FORMULARIOS.crearValorMultiple(); while(cont < total){ var aux = PLUGIN_FORMULARIOS.getValorElementoMultiple('FORM1','LEL2',i,'LELMULTIPLEDOMINIO',cont); multiple.addValor(aux.getCodigo(), aux.getDescripcion()); cont = cont+1; } e.addValorMultiple('LEL4MULTIPLE', multiple); }   i++;
 }
 DATOS_FORMULARIOS.setValorListaElementos('FORM-2', 'LEL2', lel);
}
