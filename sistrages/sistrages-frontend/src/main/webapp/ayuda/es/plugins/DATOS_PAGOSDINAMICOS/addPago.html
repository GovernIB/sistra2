addPago(PagoDinamico pago): void

DESCRIPCIÓN

  • Método que permite añadir un nuevo pago de forma dinámica a la versión del trámite.

PARÁMETROS DE ENTRADA

  • pago: variable de tipo Pago Dinámico con los valores establecidos.

EJEMPLOS

Si deseamos añadir un nuevo pago de manera dinámica a la versión de un trámite, ejecutaríamos lo siguiente:

var nif = 'nif1';
var apellido1 = 'ape1';
var apellido2 = 'ape2';
var concepto = 'concepto1';
var nombreCompleto = 'nom1';
var modelo = 'modelo1';
var unidades = 3;
if ( !PLUGIN_UTILS.esCadenaVacia( apellido1 ) )
{
nombreCompleto += ' ' + apellido1;
if ( !PLUGIN_UTILS.esCadenaVacia( apellido2 ) )
{
nombreCompleto += ' ' + apellido2;
}
}
DATOS_PAGOSDINAMICOS.setContribuyente( nif, nombreCompleto );
DATOS_PAGOSDINAMICOS.setPasarela( 'ATIB' );
DATOS_PAGOSDINAMICOS.setOrganismo( 'ORG1' );
DATOS_PAGOSDINAMICOS.setMetodosPago('TJ');
var tasa = 'TASA1';
var importe = 1;
if (PLUGIN_UTILS.esCadenaVacia(unidades)) {
DATOS_PAGOSDINAMICOS.setDetallePago( modelo, concepto, tasa, importe );
} else {
DATOS_PAGOSDINAMICOS.setDetallePago( modelo, concepto, tasa, unidades, importe );
}

El resultado de la ejecución del script "Lista dinámica de pagos" con esta sentencia será un pago que es obligatorio con los datos establecidos. Dependiendo de si se introduce un número específico de unidades, el pago se realizará una o más veces.
