setVisible(visible): void

DESCRIPCIÓN

  • Método que permite indicar si un campo es visible.

PARÁMETROS DE ENTRADA

  • visible: parámetro de tipo booleano, que si es true indica que el campo es visible, mientras que si es false establece el campo como no visible.

EJEMPLOS

Por ejemplo, si queremos que la persona que rellena el formulario no vea un campo haríamos lo siguiente:

DATOS_ESTADO.setVisible(false);
