esFormatoFecha(String formatoFecha): boolean

DESCRIPCIÓN

  • Verifica que el formato de fecha introducido no sea nulo ni vacío y sea válido.

PARÁMETROS DE ENTRADA

  • formatoFecha: Formato de la fecha. Los formatos válidos son dd/MM/yyyy y yyyy-MM-dd.

PARÁMETROS DE SALIDA

  • boolean: true si el formato de fecha es válido y false si el formato no es válido.

EJEMPLOS

Ejemplo 1 Validar una cadena de caracteres vacía ''

var valido = PLUGIN_UTILS.esFormatoFecha('');

La función esFormatoFecha retorna 'false', debido a que el valor indicado no es un formato válido.


Ejemplo 2 Validar una cadena de caracteres nula.

var valido = PLUGIN_UTILS.esFormatoFecha(null);

La función esFormatoFecha retorna 'false', debido a que el valor indicado no es un formato válido.


Ejemplo 3 Validar la cadena de caracteres 'yyyy-MM-dd'.

var valido = PLUGIN_UTILS.esFormatoFecha('yyyy-MM-dd');

La función esFormatoFecha retorna 'true', debido a que el valor indicado es un formato de fecha válido.


Ejemplo 4 Validar la cadena de caracteres 'dd/MM/yyyy'.

var valido = PLUGIN_UTILS.esFormatoFecha('dd/MM/yyyy');

La función esFormatoFecha retorna 'true', debido a que el valor indicado es un formato de fecha válido.


Ejemplo 5 Validar la cadena de caracteres '2012-12-09'.

var valido = PLUGIN_UTILS.esFormatoFecha('dd-MM-yyyy);

La función esFormatoFecha retorna 'false', debido a que el valor indicado no es un formato válido.
