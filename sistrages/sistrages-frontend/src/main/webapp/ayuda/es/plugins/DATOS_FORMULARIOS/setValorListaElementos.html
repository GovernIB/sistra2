setValorListaElementos(idFormulario, campo,valorCampoListaElementos): void

DESCRIPCIÓN

  • Método que establece un valor lista elemento a un campo del formulario actual o posterior.

PARÁMETROS DE ENTRADA

  • idFormulario: Identificador del formulario en el que quiere modificar el valor del campo.
  • campo: Identificador del campo del formulario.
  • valorCampoListaElementos: Objeto de tipo ValorListaElementos el cual contiene los diferentes valores a asignar al campo.

EJEMPLOS

Se inicializa una variable para asignarla a un campo multirregistro del formulario actual e ir añadiendo valores mediante la función addValor:

var datos = DATOS_FORMULARIOS.crearValorListaElementos(); var valorElemento=datos.addElemento(); valorElemento.addValor('codigo', '07073'); valorElemento.addValor('descripcion', 'Mallorca');

Una vez creada la variable, creado el elemento y asignados los valores, se podrá asignar al campo correspondiente.

DATOS_FORMULARIOS.setValorListaElementos('FORM2','TABLA_MUNICIPIOS',datos);

El siguiente script sirve para llenar la lista de elementos 'LEL2' de un formulario 'FORM-2' con los valores de otra lista de elementos 'LEL1' del formulario 'FORM-1' teniendo en cuenta que ambas listas cuentan con dos campos 'LTX1' y 'LTX2'.

var numeroElementos = PLUGIN_FORMULARIOS.getNumeroElementos('FORM-1','LEL1');
var lel = DATOS_FORMULARIOS.crearValorListaElementos();
var i = 0;

if (numeroElementos != null) {
 while(i < numeroElementos){
  var e = lel.addElemento();
  e.addValor('LTX1', PLUGIN_FORMULARIOS.getValorElemento('FORM-1','LEL1',i,'LTX1'));
  e.addValor('LTX2', PLUGIN_FORMULARIOS.getValorElemento('FORM-1','LEL1',i,'LTX2'));
  i++;
 }
 DATOS_FORMULARIOS.setValorListaElementos('FORM-2', 'LEL2', lel);
}
