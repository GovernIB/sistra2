invocarDominio(String idDominio, ParametrosDominio parametros): ValoresDominio

DESCRIPCIÓN

  • Método que realiza la invocación de un dominio y recupera los datos que retorna. Se utiliza este método para aquellos dominios que requieran el paso de parámetros.
  • El número de parámetros que necesita un dominio se puede identificar en la pantalla de edición del dominio. Si el dominio es global, ha de indicarse la palabra 'GLOBAL' y un punto antes del identificador del dominio y si es de entidad o área, debe indicarse el identificador de la entidad y/o área, separados por punto.

PARÁMETROS DE ENTRADA

  • idDominio: Identificador del dominio.
  • parametrosDominio: Lista de parámetros que se necesita para invocar al dominio.

PARÁMETROS DE SALIDA

  • ValoresDominio: Corresponde a los valores del dominio.

EJEMPLOS

De manera previa a la invocación de un dominio, se ha de crear en el script la lista de parámetros necesarios para la invocación, para posteriormente añadírselos al dominio. Por ejemplo, en el supuesto que necesitemos recuperar las localidades de la provincia Islas Baleares, se identificaría la provincia con el parámetro correspondiente, en este caso 07:

var parametrosDominio = PLUGIN_DOMINIOS.crearParametros(); parametrosDominio.addParametro('1', '07');

Posteriormente, se invocará el dominio LOCALIDADES añadiendo la lista de parámetros al método de invocación (supongamos que es un dominio de área):

var dLocalidades = PLUGIN_DOMINIOS.invocarDominio('CAIB.TESTS.LOCALIDADES', parametrosDominio);
