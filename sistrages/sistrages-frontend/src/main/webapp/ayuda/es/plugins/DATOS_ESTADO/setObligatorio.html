setObligatorio(obligatorio): void

DESCRIPCIÓN

  • Método que permite indicar si un campo es obligatorio.

PARÁMETROS DE ENTRADA

  • obligatorio: parámetro de tipo booleano, que si es true indica que el campo es obligatorio.

EJEMPLOS

Por ejemplo, si queremos que un campo sea obligatorio para garantizar que el usuario proporcione un valor antes de continuar, haríamos lo siguiente:

DATOS_ESTADO.setObligatorio(true);

El resultado sería que el campo se marcaría como obligatorio, y el formulario no podría enviarse sin que se complete dicho campo.

Debemos tener en cuenta que el check obligatorio no debe estar marcado, ya que tiene preferencia y el script no surtiría efecto.
