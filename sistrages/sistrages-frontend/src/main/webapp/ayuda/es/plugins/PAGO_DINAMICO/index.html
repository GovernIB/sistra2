PAGO_DINAMICO

DESCRIPCIÓN

  • Objeto que modeliza un pago que se puede añadir de forma dinámica.

MÉTODOS

  • setContribuyente(String nif, String nombreCompleto): Identificador del contribuyente del pago (Obligatorio).
  • setPasarela(String pasarela): Pasarela de pago asociada al pago (Obligatorio).
  • setOrganismo(String organismo): Organismo asociado al pago (Obligatorio).
  • setMetodosPago(String metodosPago): Métodos de pago asociados al pago. Para introducir varios métodos, separados de ';' (Obligatorio).
  • setDetallePago(String modelo, String concepto, String tasa, int importe): Permite establecer los detalles del pago, incluyendo el modelo, concepto, tasa e importe.
  • setDetallePago(String modelo, String concepto, String tasa, int unidades, int importe): Permite establecer los detalles del pago, incluyendo el modelo, concepto, tasa, unidades e importe.
