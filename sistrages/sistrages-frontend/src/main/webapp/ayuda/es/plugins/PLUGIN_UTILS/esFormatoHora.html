esFormatoHora(String formatoHora): boolean

DESCRIPCIÓN

  • Verifica que el formato de hora introducido no sea nulo ni vacío y sea válido.

PARÁMETROS DE ENTRADA

  • formatoHora: Formato de la hora. Los formatos válidos son HH:mm y HH:mm:ss.

PARÁMETROS DE SALIDA

  • boolean: true si el formato de hora es válido y false si el formato no es válido.

EJEMPLOS

Ejemplo 1 Validar una cadena de caracteres vacía ''

var valido = PLUGIN_UTILS.esFormatoHora('');

La función esFormatoHora retorna 'false', debido a que el valor indicado no es un formato válido.


Ejemplo 2 Validar una cadena de caracteres nula.

var valido = PLUGIN_UTILS.esFormatoHora(null);

La función esFormatoHora retorna 'false', debido a que el valor indicado no es un formato válido.


Ejemplo 3 Validar la cadena de caracteres 'HH:mm'.

var valido = PLUGIN_UTILS.esFormatoHora('HH:mm');

La función esFormatoHora retorna 'true', debido a que el valor indicado es un formato de hora válido.


Ejemplo 4 Validar la cadena de caracteres 'HH:mm:ss'.

var valido = PLUGIN_UTILS.esFormatoHora('HH:mm:ss');

La función esFormatoHora retorna 'true', debido a que el valor indicado es un formato de hora válido.


Ejemplo 5 Validar la cadena de caracteres 'HH-mm'.

var valido = PLUGIN_UTILS.esFormatoHora('HH-mm');

La función esFormatoHora retorna 'false', debido a que el valor indicado no es un formato válido.
