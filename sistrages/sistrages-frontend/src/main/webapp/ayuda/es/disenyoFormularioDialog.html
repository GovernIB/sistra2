DISEÑO DEL FORMULARIO

En la pantalla de 'Diseño del formulario' se puede diseñar y previsualizar formularios asociados a la versión del trámite.
Esta pantalla se compone de una cabecera, en la que se presentan las propiedads de formulario y la barra de diseño de componentes, un área en la zona izquierda en la que se presenta un editor visual del formulario, un área derecha de configuración de propiedades de los campos, y un pie compuesto por una barra de botones con diferente funcionalidad.
Cualquier cambio realizado sobre los campos en edición deberán aplicarse mediante el botón 'Aplicar cambios' para que se visualicen en el área de edición

Un tema a tener presente es que las longitudes de los campos que se quieran enviar a registro (datos interesado o representante) siguen la norma técnica de interoperabilidad de modelo de datos para el intercambio de asientos registrales entre entidades registrales (SICRES). Los valores máximos de los campos se pueden encontrar en la siguiente publicación del BOE, concretamente en las páginas 10 y 11 del documento.
SISTRA2 ya se encarga internamente de controlar los tamaños máximos establecidos en la norma y en caso que algún campo supere el tamaño máximo se truncará.

BARRA DE DISEÑO

  • Formulario: pulsando este botón se abrirá la ficha para configurar las propiedades del formulario (cabecera, gestión de páginas y plantillas de visualización).
  • Componentes: sección que presenta los botones para la inserción de componentes en el formulario. Los tipos de campos disponibles son:
    • Línea: este botón permite incluir una línea en el formulario. Cada componente deberá posicionarse en una línea.
    • Sección: este botón permite crear un campo sección. Este tipo de campos permite marcar los diferentes apartados o secciones de un formulario.
    • Aviso: este botón permite incluir avisos informativos de diferentes tipos (info, warning y error). Cada tipo de aviso presenta una iconografía ilustrativa.
    • Campo de texto: este botón permite incluir un campo de texto.
    • Campo selector: este botón permite incluir un campo selector. Este campo permite presentar diferentes valores y permitir la selección de uno o varios valores al ciudadano, dependiendo del tipo de selector.
    • Campo checkbox: este botón permite incluir en el formulario un campo casilla de verificación.
    • Campo oculto: este botón permite incluir en el formulario un campo oculto que no será visible en el formulario, pero puede ser utilizado para cálculos internos o para mostrar datos dependientes de otros campos en una plantilla PDF.
    • Campo captcha: este botón permite incluir en el formulario un campo captcha, el cual previene que bots o automatismos puedan llevar a cabo tramitaciones completas. Para completar este campo se tendrá que rellenar con los carácteres de la imagen o del dictado por voz.
    • Campo lista eleemntos: este botón permite incluir en el formulario un campo de tipo lista de elementos. Una vez se haga clic en el botón, aparecerá un nuevo componente que permitirá añadir una lista de elementos en el formulario. Para completar el diseño de los diferentes elementos de la lista, se tendrá que acceder a la "Pantalla detalle componente", donde se podrá diseñar cada elemento a mostrar en la lista.
    • Campo sección reutilizable: este botón permite incluir en el formulario un campo de tipo sección reutilizable. Una vez se haga clic en el botón, aparecerá una ventana donde se podrá seleccionar la sección reutilizable correspondiente entre las que estén dadas de alta en la pantalla de mantenimento de las secciones reutilizables.
  • Posicionamiento: sección que permite especificar la posición que se asignará a un campo al crearlo respecto a un campo seleccionado. Los valores contemplados son:
    • Previo: en caso de seleccionar este valor, el nuevo campo se creará en una posición previa a un campo seleccionado.
    • Posterior: en caso de seleccionar este valor, el nuevo campo se creará en una posición posterior a un campo seleccionado. Esta posición es la fijada por defecto.
  • Mover: sección contiene los botones para mover un campo dentro de una línea o una línea completa. No se permite mover campos entre líneas. Las opciones de movimiento disponibles son:
    • Mover a la izquiera (<): permite mover hacia la izquierda un campo seleccionado o hacia arriba una línea seleccionada. Este botón quedará deshabilitado cuando no exista la posibilidad de mover el componente más a la izquierda o la línea más arriba.
    • Mover a la derecha (>): permite mover hacia la derecha un campo seleccionado o hacia abajo una línea seleccionada. Este botón quedará deshabilitado cuando no exista la posibilidad de mover el componente más a la derecha o la lónea más abajo

EDITOR VISUAL

Este editor permite al desarrollador ver el resultado del formulario que se está creando en tiempo de diseño.
Los campos incluidos en este área son seleccionables, haciendo clic encima, de manera que en la zona derecha de la pantalla se presenten las propiedades del componente seleccionado para su edición
Los formulario diseñados se componen de páginas, y cada una de esas páginas deberán contener un conjunto de líneas sobre las que se situarán los componentes o campos.

PROPIEDADES DE COMPONENTE

  • Propiedades: en esta sección se configuran las propiedades del componente seleccionado.
    • Propiedades comunes a todos los componentes, menos Línea y Sección:
      • Identificador: código unívoco que identifica al componente dentro del formulario. Este código se deberá utilizar cuando se quiera referenciar el campo en algun script, ya sea de formulario o de flujo de tramitación. Para mantener una convención respecto a los identificadores, se recomienda la utilización de mayúsculas.
      • Columnas ocupadas: número de columnas que ocupa el componente en una línea. Cada línea puede ocupar un máximo de 6 columnas. En los componentes Línea, Sección y Aviso no aparecen, ya que ocupan todo el ancho del formulario.
      • Texto: texto multiidioma que se presentará como etiqueta del componente.
      • No mostrar texto: check que en caso de estar marcado hace que no se muestre etiqueta para el componente.
      • Ayuda contextual: texto multiidioma que se presentará como ayuda del componente al ciudadano. Este texto se mostrará en el frontal siempre y cuando el ciudadano mantenga las ayudas activas.
      • Obligatorio: indica si la cumplimentación del componente es requerida.
      • Sólo lectura: check que permite establecer el componente en modo sólo lectura, a nivel de HTML, de manera que el ciudadano no podrá introducir ningún valor en el mismo.
      • No modificable: check que permite establecer que se compruebe que un campo no var´a su valor respecto a los datos iniciales del formulario. Esta comprobación se realiza en servidor.
    • Propiedades específicas del componente Línea: No contiene
    • Propiedades específicas del componente Sección:
      • Letra: letra que aparecerá en la sección que ayuda a estructurar el contenido del formulario.
    • Propiedades específicas del componente Aviso:
      • Tipo: indica el tipo de aviso que se mostrará en el formulario, que puede ser un campo de información, un aviso (warning), un error o un texto en párrafos. Dependientdo del tipo aparecerá el texto con un icono o sin él.
    • Propiedades específicas del componente Campo de texto:
      • Tipo: permite fijar el tipo de valor esperado, de manera que se realicen unas validaciones acordes a dicho tipo. Los tipos disponibles y las propiedades relacionadas son:
        • Texto normal: este tipo de campos de texto sirve para introducir un texto en el campos.
          • Tamaño: establece el tamaño máximo en caracteres que acepta el campo.
          • Multilínea: indica si el campo admite un texto con varias líneas y, si se marca, permite especificar cuántas como máximo.
          • Forzar mayúscula: fija a mayúsculas todo el texto que se introduce.
        • Número: este tipo de campos de texto permite introducir sólo datos numéricos.
          • Precisión: establece la cantidad de cifras que se pueden introducir en la parte entera, y, en su caso, decimal, del número.
          • Formato: establece el formato que adoptará el número de forma automática y puede ser con Punto y coma (1.234,123), Coma y punto (1,234.123) y Sin formato (1234123).
          • Permite rango: indica si el campo admite un rango de cifras, de forma que si se excede dará un aviso. Si se marca, se puede indicar el rango con números negativos y 2 decimales.
          • Permite negativos: indica si se pueden introducir número menores que 0.
        • Email: este tipo de campos de texto permite introducir direcciones de correo electrónico y hacer las validaciones pertinentes.
          • Tamaño: establece la cantidad de caracteres que admite el campo como máximo.
        • Identificador: este tipo de campos de texto ofrece una serie de validaciones y formatos automáticos, especiales para datos de identificación.
          • NIF pers. física: permite indicar si es un DNI, un NIE u otros (NIF de tipo K, L y M).
          • NIF pers. jurídica: permite indicar si es un NIF.
          • Otros: permite indicar si es un NSS.
        • Código postal: permite introducir códigos postales y no tiene propiedades, pero sí validadores.
        • Teléfono: permite introducir teléfonos nacionales.
          • Teléfono: permite indicar si es un teléfono fijo y/o móvil.
        • Teléfono internacional: permite introducir teléfonos internacionales.
          • Validación precisa: marcada por defecto, permite realizar una validación por país, como que un número de España empieza por 6 o 9. Si no se marca, se hace una validación básica, como que el dato sea numérico y tenga la longitud apropiada según el país. En cualquier caso se formatea automáticamente.
        • IBAN: permite introducir este dato bancario y no tiene propiedades, pero sí validadores.
        • Fecha: permite introducir fechas de forma manual o con los controles del formulario y no tiene propiedades, pero sí validadores.
        • Hora: permite introducir horas de forma manual o con los controles del formulario y no tiene propiedades, pero sí validadores.
        • Expresión regular: permite introducir expresiones regulares, que serán validadas y evaluadas.
          • Expresión regular: permite introducir un texto que representa una expresión regular, que servirá para validar y evaluar el dato que se introduzca en ese campo.
      • Prohibir pegar: check que permite establecer si un componente tipo texto permite o no pegar texto copiado previamente.
    • Propiedades específicas del componente Campo selector:
      • Tipo: permite fijar la manera en que se presentan los valores y si se posibilita selecionar uno o más de forma simultánea. Los tipos disponibles y las propiedades relacionadas son:
        • Lista desplegable: elemento compuesto por un listado de opciones del cual solo se puede seleccionar una opción. Es obligatorio seleccionar un elemento.
          • Índice alfabético: indica si se mostrará un panel con las letras por las que empiezan los valores, para facilitar su selección.
        • Selección única: elemento compuesto por un grupo de opciones de las cuales solo se puede seleccionar una. Es obligatorio seleccionar una opción. Si se utiliza este elemento se tienen que dejar ocupadas las suficientes columnas para poder tener la vista en horizontal. En caso de que no se dejen en la vista lo veremos en vertical.
          • Orientación: establece si los elementos se mostrarán en horizontal o vertical.
        • Selección múltiple: elemento compuesto por un grupo de opciones de las cuales se puede seleccionar una, varias o ninguna.
        • Búsqueda dinámica: elemento compuesto por un grupo de opciones de las cuales se puede seleccionar una, que filtra el resultado de una lista de valores según una cadena de cáracteres introducida.
      • Tipo lista valores: permite fijar de qu´ manera se obtendrán los valores a mostrar en el campo. Las opciones disponibles son:
        • Fija: en la que se deberán introducir los valores a mostrar en una lista fija.
          • Lista valores: abre un dialogo que permite introducir una lista de valores fija para mostrar en el campo, mediante un código y un texto multiidioma.
        • Dominio: en la que se deberá seleccionar el dominio del que extraer los valores.
          • Dominio: abre un dialogo que permite seleccionar un dominio del cual obtener los valores para mostrar en el campo.
          • Campo código: texto que especifica la columan del dominio que contiene el código de cada valor a mostrar.
          • Campo descripción: texto que especifica la columan del dominio que contiene la descripción de cada valor a mostrar.
          • Parámetro dominio: abre un dialogo que permite indicar un parámetro para utilizarse en el dominio y obtener los valores en función de ese parámetro.
    • Propiedades específicas del componente Campo checkbox:
      • Valor checked: indica el valor que se va a considerar para marcar el check. Debe ser "S".
      • Valor no checked: indica el valor que se va a considerar para desmarcar el check. Debe ser "N".
    • Propiedades específicas del componente Campo oculto: sólo "Identificador".
    • Propiedades específicas del componente Campo captcha: sólo "Identificador".
    • Propiedades específicas del componente Campo Lista de elementos:
      • Nº máximo de elementos: indica cuántos elementos se pueden introducir en la lista. Tiene un máximo de 99.
      • Detalle componente lista elementos: botón que permite establecer el diseño del subformulario para los elementos que aparecerán dentro de una lista de elementos. Las propiedades específicas dentro de este subformulario aplican a los campos de texto, selectores y checkbox:
        • Mostrarse en la tabla de la lista de elementos: check que al marcarse indica que ese componente será visible en la lista de elementos tras guardar el elemento.
        • Ancho de columna en la tabla de la lista de elementos (%): indica, en caso de que el componente sea visible, el porcentaje que ocupará la columna que lo contenga, dentro de la lista de elementos. Si la suma de los porcentajes de los elementos visibles no es 100% se lanzará un aviso al guardar cerrar el detalle del subformulario.
  • Scripts: sección que presenta los scripts del campo. Los scripts disponibles son:
    • Autorelleno: script que permite asignar un valor al campo en función de valores de campos previos. Es importante que los campos de los que depende deben tener posiciones anteriores al campo sobre el que aplica el script.
    • Sólo lectura: script que permite asignar el estado "sólo lectura" al campo en función de valores de campos previos. Es importante que los campos de los que depende deben tener posiciones anteriores al campo sobre el que aplica el script.
    • Validación: script que permite realizar una validación del valor del campo. Este script permite tanto mostrar un mensaje informativo, permitiendo continuar con el trámite, o un error, de manera que no el ciudadano no pueda continuar con el trámite hasta satisfacer la validación.
    • Valores posibles: este script se muestra para campos selector con Tipo lista valores "Script", y permite establecer el conjunto de valores posibles del campo.
  • Estilos: permite modificar estilos del campo. Los estilos disponibles son:
    • Alineación texto: permite establecer la posición de la etiqueta de un campo.

BOTONADURA PIE DE PÁGINA

  • Paginación: permite cambiar de página, en caso de formulario multipágina, para la edición de componentes. La navegación permitida es:
    • Página anterior: permite ir a una página posterior del formulario, en caso de haberla, para la edición de la misma.
    • Página posterior: permite ir a una página posterior del formulario, en caso de haberla, para la edición de la misma.
  • Aplicar cambios: permite consolidar los cambios que se hayan realizado sobre un componente. Mientras no se apliquen los cambios, estos no serán visibles ni en el editor visual ni en el frontal.
  • Borrar componente: permite borrar un componente seleccionado en el editor visual.
  • Ver estructura: permite mostrar, en forma de árbol, la estructura de elementos del formulario (páginas, líneas y componentes).
  • Idioma: permite modificar el idioma a mostrar en el editor visual del formulario. Por defecto se visualiza en el mismo idioma que se está utilizando en la aplicación.
  • Previsualizar versión: permite acceder a la pantalla de configuración de previsualización de versión, a partir de la cual se podrá previsualizar la versión en desarrollo en el asistente de tramitación (vista del ciudadano).
  • Cerrar: cierra la pantalla de diseño del formulario.
