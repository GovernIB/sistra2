EDITOR DE CONTENIDO HTML

En este editor (Tiny) es posible crear contenido HTML y multiidioma, mediante un conjunto de herramientas:

  • Opciones de fuentes: permiten modificar la tipografía (negrita y cursiva), y el color de las fuentes y su fundo.
  • Opciones de inserción de objetos: permiten insertar enlaces (su destino, título, texto a mostrar y forma de abrirlos) e imágenes (su origen, que debe ser accesible desde un enlace de internet y no del dispositivo local, su descripción y su tamaño).
  • Opciones de párrafo: permiten definir la forma de alinear los párrafos (izquierda, centro, derecha y justificado), y establecer viñetas, numeraciones y sangrías.
  • Limpieza de formato: permite limpiar el formato del texto seleccionado, para dejarlo como texto plano.
  • Vista de código fuente: si la ocnfiguración global lo permite, este botón abre una ventana en la que se puede editar el contenido utilizando los TAGs propios de HTML.
