MANTENIMIENTO DE ANEXO

En la pantalla de 'Mantenimiento de anexo' puede gestionar las configuraciones del documento anexo.

CAMPOS

  • Identificador: código unívoco que identifica al anexo en la aplicación. Cualquier referencia al anexo en los scripts de la versión se realizará utilizando este código.
  • Descripción: texto multiidioma de presentación del anexo en el asistente de tramitación. Esta será la denominación del anexo que visualizará el tramitador en el asistente de tramitación.
  • Tipo Documento ENI: indica el tipo de documento clasificado dentro del Esquema Nacional de Interoperabilidad (ENI). Cada tipo TD corresponde a una categoría definida por el ENI para clasificar documentos administrativos electrónicos, garantizando interoperabilidad y trazabilidad entre sistemas públicos.
  • Obligatoriedad: permite configurar la obligatoriedad de anexar el documento en el asistente de tramitación. Los valores posibles son:
    • Obligatorio: si se marca esta opción, será obligatorio el anexado del documento en el asistente. En caso contrario, no se podrá con la cumplimentación del trámite.
    • Opcional: si se marca esta opción, el anexado del documento será opcional.
    • Depende: si se marca esta opción, la obligatoriedad de anexado del documento dependerá del script 'Establecer dependencia'.
    • Establecer dependencia: script que permite establecer la obligatoriedad de un documento según otros datos del trámite (dominios, datos de un formulario previo, datos de sesión, etc.). Únicamente se tendrá en cuenta el valor de este script si se ha fijado previamente la obligatoriedad 'Depende'.
  • Ayuda: en este apartado se configura la información relativa al documento anexo, que se mostrará al ciudadano en el asistente de tramitación para facilitar la aportación:
    • Fichero: esta opción permite al desarrollador adjuntar un documento que se mostrará en el asistente de tramitación a modo de plantilla del documento a anexar.
    • URL: permite indicar un enlace de la que el ciudadano pueda descargar, desde el asistente de tramitación, un documento a modo de plantilla del documento a anexar.
    • Mensaje (HTML): posibilita añadir un mensaje, con soporte HTML, que se mostrará en el asistente de tramitación como información de interés para el ciudadano para la aportación del documento.
  • Presentación electrónica: configuraciones y restricciones relativas a la aportación electrónica del documento por parte del ciudadano:
    • Num. instancias: indica, en formato numérico entero, el número de ficheros que pueden ir adjunto en un mismo anexo. Si el anexo requiere firma no se podrá indicar un número superior a 1 instancia.
    • Extensiones: indica las extensiones de ficheros que se permitirán adjuntar para el documento anexo. Si se marca “Todas” se permitirá cualquier extensión, y en caso de marcar “Personalizadas” se deberán consignar en el campo de texto las extensiones deseadas, separadas por punto y coma (;).
    • Tam. máximo: indica, en formato numérico entero, el tamaño máximo de los ficheros que se permitirán adjuntar. Además, dicho tamaño se puede expresar en kilobytes (KB) o megabytes (MB), marcando la opción correspondiente.
    • Requiere firma: solo podrá activarse si el número de instancias es 1 e indica que el anexo deber ser firmado, bien mediante el asistente (a través del correspondiente plugin de firma cliente) o anexado ya firmado. En caso de que no se active “Requiere firma”, no se pedirá firma en el asistente, y se podrá anexar el archivo con o sin firma, sin realizarse ningún control, salvo el del tamaño y extensión.
    • Validar firmantes: valida que el anexo esté firmado por los firmantes establecidos, que por defecto será el usuario que inició el trámite.
    • Establecer firmantes: script que establece los firmantes del anexo (si no se establece, será el usuario autenticado).
    • Script de validación: script que permite llevar a cabo validaciones tras la aportación del documento por parte del ciudadano. Este script se ejecuta al anexar el documento.

OPERATIVA

  • Guardar: cierra la pantalla guardando los cambios.
  • Cancelar: cierra la pantalla sin guardar los cambios.

RESTRICCIONES

En relación a la configuración de extensiones y firma, deben tenerse en cuenta las siguientes restricciones.

  • Para poder firmar anexos, el trámite no puede ser anónimo.
  • La validación de firmantes se configura de forma automática según nivel de seguridad:
    • Nivel alto / sustancial con certificado: se queda habilitada la validación de firmantes
    • Nivel bajo / sustancial: se queda deshabilitada la validación de firmantes
  • También se Verifica la configuración de extensiones según nivel de seguridad:
    • Nivel alto / sustancial con certificado: Se permite anexar sólo PDF (u otras extensiones según configuración de entidad.
    • Nivel bajo / sustancial: Solo se permite PDF.
