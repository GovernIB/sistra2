VENTANA DE FILTROS

En la ventana 'Ventana de Filtros' se puede seleccionar el criterio para obtener resultados más específicos, dependiendo del evento seleccionado:

  • Filtro de Error: se podrá filtrar por los errores mostrados en la plataforma. Permite buscar por tipo de error y/o por texto contenido en la traza.
  • Filtro de Pagos: se podrá filtrar por los distintos métodos de pago para los eventos:
    • TR_PAE - Pago electrónico verificado
    • TR_PAN - Pago electrónico no verificado
    • TR_PAC - Pago cancelado
  • Filtro de Firma: se podrá filtrar por los distintos métodos de firma para los eventos:
    • TR_SGO - Fin firma OK
    • TR_SGX - Fin firma KO

Opciones de filtrado

  • Búsqueda por : Dependiendo del tipo de evento, se podrá filtrar por distintos métodos de búsqueda:
    • Buscar por tipo de error: Permite activar la búsqueda por tipo de error. Al marcar esta opción, se habilita una tabla con los diferentes tipos de error disponibles, donde se pueden seleccionar uno o varios para filtrar los resultados.
    • Buscar por método de pago: Permite activar la búsqueda por método de pago. Es la opción por defecto para este tipo de evento. Se mostrará una tabla con los diferentes métodos de pago, donde se pueden seleccionar uno o varios para filtrar los resultados.
    • Buscar por método de firma: Permite activar la búsqueda por método de firma. Es la opción por defecto para este tipo de evento. Se mostrará una tabla con los diferentes métodos de firma, donde se pueden seleccionar uno o varios para filtrar los resultados.
  • Buscar por texto en la traza: Solo permitida para el evento de ERROR. Permite activar la búsqueda por texto. Al marcar esta opción, se habilita un campo de texto donde se puede introducir una palabra o frase para buscar en las trazas de error.

Operativa

  • Botón Buscar: Aplica el filtro seleccionado y muestra los errores que cumplen los criterios.
  • Botón Cancelar: Cierra el diálogo sin aplicar cambios.
